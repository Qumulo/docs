      C-192T, C-432T, and K-432T

      Important
      The C-192T, C-432T, and K-432T platforms reached their End of Availability on May 9, 2025. End of Platform Support (EoPS) is May 9, 2030.
      Note
      This page is reference material (drive bay layout) for the C-192T, C-432T, and K-432T platforms. For replacement procedures, see Replacing Hardware Components and Chassis Replacement.

      This page provides drive bay mapping for the C-192T, C-432T, and K-432T (Q2U_1 platform).

      HDD Drawers (24 bays across 3 drawers)

      The chassis contains 24 HDDs across three top-load drawers, labeled in sequence from top to bottom.

      Caution
      When the HDD drawer is full, it is very heavy. Adding extra weight (such as resting tools on the drawer) can cause the rails to deform.

      Rear NVMe Drives

      The rear NVMe drives are located at the back of the chassis in a 2 × 3 configuration.

             +---------+---------+---------+
       | NVMe 25 | NVMe 26 | NVMe 27 |
       +---------+---------+---------+
       | NVMe 28 | NVMe 29 | NVMe 30 |
       +---------+---------+---------+

      NIC Ports

      The Qumulo C-series platform uses a networking configuration where both back-end and front-end traffic are handled by the same NIC. Each node has 2 NIC ports on the rear of the chassis (plus a separate IPMI port).

                       NIC card (rear)
              +---------+
              | Port 1  |   <- top
              +---------+
              | Port 2  |   <- bottom
              +---------+

      Linux interface names depend on NIC manufacturer:

      NIC Manufacturer Port Location Port Label
      Mellanox Top 1 (eth3)
      Mellanox Bottom 2 (eth4)
      Broadcom Top 1 (eth0)
      Broadcom Bottom 2 (eth1)
      Caution
      Don’t use the LAN On Motherboard ports. Only use the external NIC ports for connections.
      Note
      For reliability, both ports on each node should be connected. If a single connection fails, the node will be unavailable.

      Boot Drive

      The boot drive is an internal M.2 SSD located on the motherboard.

      Caution
      Before removing the boot drive, contact the Qumulo Care team for detailed instructions on how to proceed.
