The Provisioner stores all necessary state information in the Parameter Store and shuts down automatically when it completes its tasks.

<ol>
  <li>In AWS Systems Manager, click <strong>Application Management &gt; Parameter Store &gt; /qumulo/&lt;my-unique-deployment-name&gt;/last-run-status</strong>.</li>
  <li>On the <strong>History</strong> tab, click <span class="emoji">⚙️</span>.</li>
  <li>In the <strong>Preferences</strong> dialog box, click <strong>Parameter history properties > Value > Confirm</strong>.</li>
</ol>
